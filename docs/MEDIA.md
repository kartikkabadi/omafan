# Artwork and screenshots

`assets/omafan-banner.png` is promotional artwork created with the built-in
image-generation tool for Omafan. Its black, white and neutral-gray palette
matches Omarchy's Vantablack theme. The sculpted fan is an illustration, not an
application screenshot or a hardware-performance claim. The root `preview.png`
is a copy of that banner for the community directory.

The three images in `assets/screenshots/` are actual captures of Omafan's
Linked, Separate and Auto views on the documented M1 Pro MacBook Pro. They are
cropped to the application panel and contain no surrounding desktop content.
They are separate from the generated artwork. Capturing the views exercised
the saved-profile round trip; it did not verify a physical reboot or suspend.

The Omafan artwork was created for this project. Upstream code attribution and
MIT copyright are retained in [NOTICE.md](../NOTICE.md) and [LICENSE](../LICENSE).
